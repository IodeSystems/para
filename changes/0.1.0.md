# 0.1.0

## People

- The Agenda is the home screen in the terminal UI and the web app. The old Today address goes to the Agenda.
- Every task row has actions: Resolve, Start, Block, Assign, Give to agent, Due, Later, Cut, Investigate. Resolve closes a task as done, partial, dropped, duplicate, or superseded, with a note and follow-ups.
- Give to agent hands a task to an agent as queued work. The row says "Agent working" while that work is open.
- Update on a task: write what happened in your own words. An agent sorts it into action items, questions, commitments, and follow-ups for you to review.
- Meetings, calls, work with someone, and commitments are now kinds of task. Older meeting files still read and work. A vault upgrade step can rewrite them.
- Later can wait on another item or on a condition, not only on a date.
- Review has one "Request changes" action. It replaces Note and Send back, and only a change request needs text.
- Edit any document from the terminal UI and the web app.
- Stalled Asks show a path log and next moves: other ways to reach the person, a colleague with the same role, an introduction, a call, or a self-serve answer.
- The friction report groups Asks by reason, domain, or policy and never ranks people.
- Align compares a goal with reality and records when you last did it. Health flags goals that were never aligned.
- The web app can show browser notifications when something needs you. It is off until you turn it on.
- Text fields in the terminal UI wrap and take several lines. "Find context" is now "Investigate", and "Capture" is "Add to inbox".
- `para upgrade` pulls and installs a new version from a checkout. `para changes` shows these notes. `para vault upgrade` brings a vault to the current format.

## Agents

- New tools: task_resolve, task_delegate, task_update, doc_edit, attempt_add, rfx_nudge, rfx_path_add, rfx_paths, note_edit, align_scope, align_record, report_friction, changes.
- New prompts: sort_update, align_vault, ingest_source. Use sort_update on agent work titled "Sort update".
- Changed rule: a request for changes replaces note and send back in review. Only a change request carries text.
- A meeting is a task of kind meeting. meeting_add, meeting_show, meeting_schedule, meeting_hold, and meeting_cancel work on both shapes.
- task_resolve allows done from an agent. Every other outcome is a proposal. A new task needs done_when when an agent adds it.
- Tasks take parent, kind, scheduled, end, with, and rfx. A parent does not wait on its children.
- Agent work titled "Work on: ..." comes from task_delegate. Report with request_done and sources.
- Vault upgrade steps may file agent work titled "Vault upgrade: ...". Read the instructions in it, file one proposal, and stop. The step clears when its done test finds nothing.
- When the server instructions say para changed since your last session, call changes.
