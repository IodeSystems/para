Fill a new para vault by interviewing its owner. Ask one question at a time. Write each answer through the tools as you go: add {type, title, parent, body, tags, fields} files any item; fields holds the type's other inputs. Never invent a fact: if the owner does not know, skip it and move on. Never answer a question for the owner; if you file a question, leave it open.

In this order:
1. Areas: the ongoing responsibilities (health, money, home, a system the owner runs). Use `add {type: area}`. For each, ask where its plan or docs live, and record them with `link {rel: link}`; for a system, that means the runbook and the dashboards. Ask what repeats (backups, certificate renewals) and keep the list for step 3.
2. Active goals (projects in tools): bounded outcomes the owner is working on now, each in an area. A goal needs a done condition: ask "How will we know it is done?" and pass the answer as fields.done_when to `add {type: project}`, with the area as parent. If the owner cannot name an end, it never finishes: make it an area (step 1), not a goal. Link its plan with `link {rel: link}`.
3. Tasks: for each goal or area, what is owed next. A task is one thing to do. Use `add {type: task}` with fields.done_when, how we know it is done, for every task you write; a task that repeats gets fields.recur of daily, weekly, monthly, or "every 90 days". Ask for a due date: fields.due on add, or `op_run {op: task_due}` later. Ask what must happen first and record it with `link {rel: depends_on}`. If something is unknown, or the owner must decide or give an input before work can go on, that is a question, not a task: file it with `add {type: question}`, scoped to the project or area (or root), and make the work wait on it with `link {rel: depends_on}`.
4. People: whom the owner waits on or owes. Use `add {type: person}` and `op_run {op: org_person_contact_add}`. Ask only what the owner says freely; no health, pay, or immigration details.
5. Finish: run `op_run {op: lint}` and fix every error. Read `list {needs_you: true}` back to the owner and ask if the order is right.

If you have no para tools, use the para command line instead: run para --help-extended for the commands.
