Use para from dun.

1. Add one server per vault to `servers` in .dun/dun.local.json for this machine,
   or dun.json for the project:

{{config}}

2. Check with /mcp.

3. Start with a prompt, as a slash command:
   /para-<vault>:orient      what para is, and how to work a vault
   /para-<vault>:bootstrap   an interview that fills a new vault

4. Events record the actor `dun`. Change "--actor" to tell agents apart.

5. A session can wait for queued work with no token cost. This blocks until a
   request can be claimed, so run it as a background job, then call `request_next`:
   $ para request wait --timeout 1h

Para cannot stop an agent from using other tools. To enforce "no external action
without approval", use a dun hook or server-level limits.
